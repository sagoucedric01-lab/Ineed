## Stratégie de tests

- **Unitaires** : machine à états, scoring de dispatch, calculs de commission/remboursement, formatage XOF/téléphone/dates.
- **Intégration** : vraie base PostGIS + Redis (Testcontainers ou services CI) — concurrence, contraintes, webhooks, idempotence. Pas de mock de la base pour les règles critiques.
- **E2E API** : parcours complets client ↔ pro ↔ admin via HTTP.
- **Admin** : Playwright.
- **Mobile** : tests de widgets + tests d'intégration Flutter sur émulateur Android en CI ; iOS sur runner macOS. **Les tests sur appareils physiques ne peuvent pas être réalisés depuis cet environnement.**
- Aucun résultat ne sera annoncé comme réussi sans sortie réelle de la commande.
